Tam Giác Vuông

Tam giác có một góc vuông (90 độ). Cạnh đối diện góc vuông là cạnh huyền, thỏa mãn định lý Pythagore kinh điển.

Công Thức Tính

  • Cạnh huyền: c = √(a² + b²)
  • Diện tích: S = a × b / 2
  • Chu vi: C = a + b + c
  • Bán kính ngoại tiếp: R = c/2
  • Bán kính nội tiếp: r = (a + b - c)/2
